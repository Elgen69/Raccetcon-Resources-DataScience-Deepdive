# Raccetcon Resources: Data Science Deep Dive
## From Analytics Foundations to Applied AI Systems

This repository contains the complete set of resources, guides, and coursework materials for the **Raccetcon Data Science Deep Dive** session.

### 📚 Overview
The materials follow a structured journey through the data science life cycle, emphasizing the philosophy: **Process First, Models Second.**

### 📂 Contents

#### 1. Foundations: Analytics Coursework
Detailed coursework from the Data Analytics foundation, covering:
- **EDA (Exploratory Data Analysis)**: The cornerstone of understanding data.
- **Clustering**: K-Means, DBSCAN, and Hierarchical grouping.
- **Regression & Feature Engineering**: Bridging domain knowledge with code.
- **Classic ML**: KNN, SVM, and Decision Trees as analytical tools.

#### 2. Hands-on Activities (DataLab)
Guided coding exercises on the DataCamp DataLab platform:
- **Analyzing Crime in Los Angeles**: Structured EDA in Python to uncover frequencies and age-group patterns.
- **Student Mental Health**: SQL-based analysis investigating the relationship between length of stay and mental health scores.

#### 3. Case Study: Malaria Detection ML Pipeline
A comprehensive look at an undergraduate thesis project deploying deep learning for healthcare:
- **YOLO Stage**: Automated cell detection in blood smear slides.
- **CNN Ensemble**: Weighted soft-voting (Softmax) across EfficientNet, ResNet, and DenseNet.
- **Grad-CAM**: Explainable AI generating heatmaps to build clinician trust.
